## บันทึกสำหรับผู้สอน

**การจัดสรรเวลา** อ่านสถานการณ์ 45 วิ · ข้อ 1 45 วิ · ข้อ 2 55 วิ · ข้อ 3 40 วิ · ข้อ 4 60 วิ
รวมประมาณ 4 นาที 5 วินาที เหลือ buffer ราว 1 นาที

**ทำไมข้อ 3 จึงสำคัญที่สุด** หัวใบงานให้กรอก URL มาแล้วก็จริง แต่ URL พิสูจน์เพียงว่าเว็บมีอยู่
ไม่ได้พิสูจน์ว่าเจ้าตัวเข้าใจว่าทำไมมันขึ้น นักศึกษาที่ให้เพื่อนกดให้จะกรอกหัวใบงานได้ครบเหมือนกัน
ข้อที่แยกสองกลุ่มนี้ออกจากกันคือกฎ "ชื่อ repository ต้องตรงกับ username ทุกตัวอักษร"
ซึ่งจำได้จากการลงมือทำเท่านั้น เดาไม่ได้ ขีดกลางใน `anya-forger` ใส่ไว้ด้วยเหตุผลนี้

**ทำไมสถานการณ์แสดงสองฝั่ง** ฝั่งซ้ายเป็นซอร์ส `README.md` ฝั่งขวาเป็นสิ่งที่คนอื่นเห็นจริง
รูปแบบนี้ทำให้บทเรียนที่คมที่สุดของ Mission 0 มองเห็นได้ด้วยตา — **GitHub ตัด `<script>` ทิ้ง
ตอน render บรรทัด API key จึงไม่ปรากฏฝั่งขวา แต่ใครก็กดดูซอร์สได้**
นักศึกษาที่ไม่ขีดเส้นใต้บรรทัดนั้นเพราะคิดว่า "ไม่แสดงผลก็ไม่เป็นไร" คือกลุ่มที่ต้องอธิบายเพิ่มตอนเฉลย

ผลพลอยได้อีกอย่างคือนักศึกษาได้เห็นว่า `#`, `##`, `-` และ `**...**` ในซอร์สกลายเป็นอะไรบ้าง
ซึ่งเชื่อมกับเทมเพลต profile README ใน `starter/` โดยตรง

**ทำไมโจทย์ต้องระบุสองเงื่อนไข** โจทย์ต้องบอกทั้ง "ใช้ GitHub Pages" และ "ต้องการ URL ระดับบนสุด
ไม่มีชื่อ repository ต่อท้าย" ขาดข้อใดข้อหนึ่งไม่ได้ เพราะ GitHub Pages เปิดได้สองแบบ

| แบบ | ชื่อ repository | URL ที่ได้ |
|---|---|---|
| **user site** — แบบที่ใบงานให้ทำ | ต้องเป็น `<username>.github.io` เท่านั้น | `https://<username>.github.io` |
| **project page** | ตั้งชื่ออะไรก็ได้ | `https://<username>.github.io/<ชื่อ repo>` |

ถ้าโจทย์ไม่บีบให้เป็น user site นักศึกษาตั้งชื่อ repo ว่าอะไรก็ตอบถูกได้หมด ข้อนี้จะวัดอะไรไม่ได้เลย
ควรใช้ตารางนี้อธิบายตอนเฉลย เพราะเป็นจุดที่นักศึกษาสับสนบ่อยที่สุด

**ทำไมใช้ตัวละครสมมติ** สถานการณ์ต้องแปะเบอร์โทร ที่อยู่ และตารางเรียนปลอมลงบนชื่อหนึ่ง
จึงต้องไม่ใช่ชื่อบุคคลจริง เพราะขัดกับสิ่งที่ Mission 0 กำลังสอนอยู่พอดี
เปลี่ยนเป็นตัวละครสมมติตัวอื่นได้ ขอให้ username มีขีดกลางหรือตัวเลข และไม่มีตัวพิมพ์ใหญ่
เพราะ GitHub Pages เสิร์ฟ URL เป็นตัวพิมพ์เล็ก จะเกิดข้อโต้แย้งตอนตรวจ

**น้ำหนักคะแนน** ข้อสอบ 5 นาทีมีค่าความเที่ยงต่ำโดยธรรมชาติ ไม่ควรให้น้ำหนักเกิน 10% ของเกรด
หลักฐานหลักของหน่วยนี้คือ URL เว็บไซต์จริงและใบงานหน้า 1 ที่ลงชื่อแล้ว
ข้อสอบนี้ทำหน้าที่ยืนยันว่าเจ้าตัวเข้าใจเกณฑ์ที่ใช้ ไม่ใช่ลอกเพื่อนมา
