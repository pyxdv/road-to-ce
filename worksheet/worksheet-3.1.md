## จุดประสงค์เชิงพฤติกรรม (LLO)

1. อธิบายลำดับการทำงานตั้งแต่ผู้ใช้พิมพ์ URL จนหน้าเว็บแสดงผล โดยระบุบทบาทของ DNS, IP address,
   HTTP และ TLS ได้ถูกต้อง
2. สร้างและ deploy เว็บไซต์ส่วนบุคคลด้วย GitHub Pages ให้เข้าถึงได้จริงจากเครือข่ายภายนอก
3. ใช้คำสั่ง `nslookup`, `ping` และเครื่องมือ DevTools ตรวจวัดค่าจริงของเว็บไซต์ตนเอง
   พร้อมแปลความหมายของค่าที่วัดได้
4. เรียบเรียงเนื้อหาและปรับรูปแบบการแสดงผลของหน้าเว็บและหน้า GitHub profile
   ให้สื่อสารตัวตนได้ตรงตามความเป็นจริงและอ่านง่าย
5. ตรวจสอบและจัดการข้อมูลส่วนบุคคลของตนเองก่อนเผยแพร่สู่สาธารณะได้อย่างเหมาะสม

| LLO | เชื่อมโยง CLO | มิติ K/S/E/C |
|---|---|---|
| LLO1 | CLO2 | K |
| LLO2 | CLO2 | S |
| LLO3 | CLO2, CLO8 | K, S |
| LLO4 | CLO8 | S, C |
| LLO5 | CLO7 | E, C |

### Mission 1 — Go Live · เอาเว็บขึ้นออนไลน์ (30 นาที)

1. สร้าง repository สาธารณะชื่อ `<github-username>.github.io` — ชื่อต้องตรงกับ username ทุกตัวอักษร
2. เปิด [`starter/index.html`](../starter/index.html) กด **Copy raw file** → repository ของตนเอง →
   **Add file** → **Create new file** → ตั้งชื่อ `index.html` → วาง → Commit
3. Settings → Pages → Source เลือก **Deploy from a branch** → branch `main` → `/ (root)` → Save
4. **ทดสอบจากเครือข่ายภายนอก** ใช้มือถือ **ปิด Wi-Fi ใช้อินเทอร์เน็ตมือถือ** แล้วเปิด URL ของตนเอง
   ถ่ายภาพหน้าจอเก็บไว้ส่งงาน

### Mission 2 — Make It Yours · ทำให้เป็นของเรา (30 นาที) ← ภารกิจหลัก

แก้เฉพาะบล็อก `const ME = {` ในไฟล์ `index.html` ไม่ต้องแตะส่วนอื่น

| ช่อง | ใส่อะไร | หมายเหตุ |
|---|---|---|
| `github` | GitHub username ของตนเอง | **ระบบดึงรูปโปรไฟล์จาก GitHub มาแสดงให้เอง ไม่ต้องอัปโหลดรูป** |
| `name` | ชื่อที่ต้องการให้แสดง | ใช้ชื่อเล่นได้ |
| `role` | บอกว่าเราคือใคร | เช่น นักศึกษาวิศวกรรมคอมพิวเตอร์ ปี 1 มทร.อีสาน |
| `tagline` | หนึ่งประโยคแนะนำตัว | ส่วนที่คนจำได้มากที่สุด เขียนให้เจาะจง |
| `about` | ข้อความแนะนำตัว 2-3 บรรทัด | มาจากไหน สนใจอะไร อยากไปทางไหน |
| `learning` | สิ่งที่กำลังเรียนรู้ | 2-5 รายการ เขียนเฉพาะที่เรียนอยู่จริง |
| `works` | ผลงาน | ปี 1 เทอมแรกยังว่างได้ ปล่อย `[]` ไว้ หน้าเว็บจะขึ้นข้อความให้เอง |
| `links` | ช่องทางติดต่อ | ลิงก์สาธารณะเท่านั้น |
| `theme` | ธีมสี | `ocean` · `sunset` · `forest` · `grape` · `mono` · `mono-light` <br>ห้าตัวแรกพื้นหลังเข้ม `mono-light` พื้นหลังสว่าง |

**เช็กลิสต์การออกแบบ** (อิงใบความรู้ หัวข้อ 9)

- [ ] ย่อหน้าต่างเบราว์เซอร์ให้แคบเท่าจอมือถือ ข้อความยังอ่านได้ ไม่ล้นออกนอกจอ
- [ ] ถอยห่างจากจอสองเมตร ยังบอกได้ว่าส่วนใดสำคัญที่สุด
- [ ] เปลี่ยนธีมสีจากค่าตั้งต้นแล้ว หรือยืนยันว่าเลือกค่าตั้งต้นเพราะชอบจริง
- [ ] แก้ค่าในส่วน CSS อย่างน้อยหนึ่งค่าแล้ว และอธิบายได้ว่าแก้อะไร ผลเป็นอย่างไร
- [ ] ไม่มีข้อความตัวอย่างหลงเหลือ
- [ ] `tagline` เจาะจงพอที่เพื่อนจะจำได้
- [ ] ให้เพื่อนอ่าน 10 วินาที แล้วเพื่อนบอกได้ว่าเราสนใจอะไร

> **แก้ค่าใน CSS อย่างน้อยหนึ่งค่า** ส่วน `style` ในไฟล์เดียวกันคือ CSS ทั้งหมด
> เลือกแก้อย่างน้อยหนึ่งค่าแล้วบันทึกลงใบงานว่าแก้อะไรและผลเป็นอย่างไร ลองทีละค่าจะเห็นผลชัดกว่า:
> `max-width` ของ `.wrap` = ความกว้างเนื้อหา · `line-height` ของ `body` = ระยะห่างบรรทัด ·
> `margin-top` ของ `section` = ระยะห่างระหว่างหัวข้อ แก้แล้วไม่ชอบก็ย้อน commit กลับได้

### Mission 3 — Trace the Request · ตามรอยข้อมูล (10 นาที)

| สิ่งที่ต้องหา | หาจากที่ใด |
|---|---|
| IP address ของเว็บตนเอง | `nslookup <โดเมนของตนเอง>` |
| RTT เฉลี่ย | `ping <โดเมนของตนเอง>` |
| status code ของหน้าแรก | DevTools → Network → Status |
| เวอร์ชัน HTTP | DevTools → Network → Protocol หรือแผงท้ายหน้าเว็บของตนเอง |
| ค่า TTFB | แผงข้อมูลการเชื่อมต่อท้ายหน้าเว็บของตนเอง หรือ DevTools → Timing |

> **DevTools อยู่ที่ไหน** เป็นเครื่องมือที่ติดมากับ browser อยู่แล้ว ไม่ต้องติดตั้งเพิ่ม
> เปิดด้วย `F12` หรือ `Ctrl+Shift+I` บน Windows และ `Cmd+Option+I` บน macOS
> หรือคลิกขวาบนหน้าเว็บแล้วเลือก **Inspect** ใช้ Chrome หรือ Edge จะตรงกับใบงานที่สุด
>
> - ตารางจะว่างเปล่าถ้ายังไม่โหลดหน้าใหม่ เพราะ DevTools บันทึกเฉพาะที่โหลดหลังจากเปิดแผงแล้ว
>   ให้กด `Ctrl+F5` (macOS: `Cmd+Shift+R`) หนึ่งครั้ง
> - คอลัมน์ **Protocol ถูกซ่อนไว้ตั้งแต่ต้น** ถ้าหาไม่เจอให้คลิกขวาที่หัวตาราง
>   แถวที่เขียน Name Status Type แล้วติ๊ก Protocol เพิ่มเข้ามา
>   หรือใช้บรรทัด **HTTP version** ในแผงท้ายหน้าเว็บของตนเองแทนก็ได้ เป็นค่าเดียวกัน
> - ค่า TTFB ใน DevTools อยู่ที่แท็บ **Timing** บรรทัด *Waiting for server response*
> - โทรศัพท์มือถือไม่มี DevTools ภารกิจนี้จึงต้องทำบนคอมพิวเตอร์
>   ส่วนภาพถ่ายหน้าจอมือถือเป็นหลักฐานคนละชิ้นกัน

**คำถาม**

1. จากค่า RTT ที่วัดได้ ประมาณว่า server อยู่ห่างออกไปกี่กิโลเมตร พร้อมแสดงวิธีคิด (ใบความรู้ หัวข้อ 5)
2. เมื่อมีคนพิมพ์ URL ของเราแล้วกด Enter จนหน้าเว็บแสดงผล มีสี่ขั้นตอนหลักอะไรบ้าง ตามลำดับ
   (ใบความรู้ หัวข้อ 1–4)

### Mission 4 — GitHub Profile · หน้าโปรไฟล์ของเรา (10 นาที)

หน้า `github.com/<username>` คือหน้าที่คนอื่นเห็นเมื่อค้นชื่อเราเจอ **ในสายงานนี้ผู้ว่าจ้างและรุ่นพี่
เปิดดูหน้านี้ควบคู่ไปกับ resume**

> ถ้าสร้าง repository ที่ **ชื่อเดียวกับ username เป๊ะ ๆ** แล้วใส่ `README.md` ไว้
> เนื้อหาในไฟล์นั้นจะขึ้นแสดงบนสุดของหน้า profile

1. New repository → ตั้งชื่อเป็น username ของตนเอง → Public → ติ๊ก Add a README file
   (ถ้าตั้งชื่อถูก GitHub จะขึ้นว่า *You found a secret!*)
2. คัดลอกเนื้อหาจาก [`starter/profile-readme/profile-README-template.md`](../starter/profile-readme/profile-README-template.md)
   มาวางใน `README.md`
3. แก้ข้อความในวงเล็บ `[ ]` ให้เป็นของตนเอง ใส่ลิงก์เว็บไซต์จาก Mission 1 แล้ว Commit

> **ใช้ข้อความเดิมจาก Mission 2 ได้เลย** หนึ่งประโยคแนะนำตัว รายการสิ่งที่กำลังเรียนรู้ และความสนใจ
> ใช้ชุดเดียวกับที่เขียนไว้บนหน้าเว็บได้ทั้งหมด ไม่ต้องคิดใหม่ ภารกิจนี้จึงใช้เวลาเพียง 10 นาที

> **เขียนอะไรดี ในเมื่อยังไม่มีผลงาน** เขียนตามจริงว่ากำลังเรียนอะไรและสนใจไปทางไหน
> การเขียนตามจริงดูน่าเชื่อถือกว่าเขียนเกินตัวเสมอ คนที่อ่าน profile ของนักศึกษาปี 1
> รู้อยู่แล้วว่าเราอยู่ปี 1 — สิ่งที่เขาอยากเห็นคือทิศทางและความต่อเนื่อง

> **อยากได้หน้าที่ดูเท่กว่านี้** ทำแบบพื้นฐานให้เสร็จก่อนในคาบ แล้วนอกเวลาเลือกทำต่อได้อีก 4 สไตล์
> ที่ [`starter/profile-readme/styles/`](../starter/profile-readme/styles/) — minimalist (เรียบ) ·
> learn-in-public (เล่าเส้นทางการเรียนรู้) · visual (badge และการ์ดสถิติ) · terminal (แนว command line)
> ดูโปรไฟล์จริงของนักพัฒนาทั่วโลกและของไทยได้ที่
> [`gallery.md`](../starter/profile-readme/gallery.md) และดูตัวอย่างที่กรอกครบแล้วที่
> [`example-filled.md`](../starter/profile-readme/example-filled.md)
