# starter — เว็บไซต์ตั้งต้นสำหรับ Mission 1

## วิธีใช้ (ไฟล์เดียวจบ)

`index.html` ไฟล์เดียว มีทั้ง HTML, CSS และ JavaScript อยู่ในตัว ไม่ต้องดาวน์โหลดไฟล์อื่น

1. เปิด [`index.html`](index.html) กดปุ่ม **Copy raw file** ที่มุมขวาบน
2. ไปที่ repository ของตนเอง → **Add file** → **Create new file**
3. ตั้งชื่อไฟล์ว่า `index.html` แล้ววางโค้ดลงไป
4. กด **Commit changes**

แก้ให้เป็นข้อมูลของตนเองโดยแก้เฉพาะบล็อก `const ME = {` ใกล้ด้านบนของไฟล์
ทุกช่องมีคำอธิบายกำกับไว้แล้วว่าใส่อะไร

| ช่อง | ใส่อะไร |
|---|---|
| `github` | GitHub username — **ระบบดึงรูปโปรไฟล์มาแสดงให้เอง ไม่ต้องอัปโหลดรูป** |
| `name` · `role` | ชื่อที่ใช้แสดง และบอกว่าเราคือใคร |
| `tagline` | หนึ่งประโยคแนะนำตัว เขียนให้เจาะจง |
| `about` | ข้อความแนะนำตัว 2-3 บรรทัด |
| `learning` | สิ่งที่กำลังเรียนรู้ 2-5 รายการ |
| `works` | ผลงาน ปี 1 เทอมแรกปล่อย `[]` ไว้ได้ หน้าเว็บจะขึ้นข้อความให้เอง |
| `links` | ช่องทางติดต่อ ลิงก์สาธารณะเท่านั้น |
| `theme` | ธีมสี: `ocean` · `sunset` · `forest` · `grape` · `mono` · `mono-light` (พื้นสว่าง) |

เนื่องจากเป็นไฟล์เดียว จึงไม่มีปัญหาเรื่อง path ผิดหรือไฟล์ขาด และเปิดจากเครื่องตนเองก็ทำงานได้ครบ

## อยากปรับให้ลึกกว่าที่ช่อง ME ให้

ส่วน `<style>` ในไฟล์เดียวกันคือ CSS ทั้งหมดของหน้านี้ ลองแก้ทีละอย่างแล้วดูผล

- `max-width` ของ `.wrap` — ความกว้างของเนื้อหา
- `line-height` ของ `body` — ระยะห่างระหว่างบรรทัด
- `margin-top` ของ `section` — ระยะห่างระหว่างหัวข้อ
- บล็อก `[data-theme="..."]` ต้นส่วน `<style>` — ถ้าอยากผสมสีเอง
- `--surface` ใน `:root` — ความเข้มของพื้นการ์ดผลงานและแผงข้อมูล

แก้แล้วไม่ชอบก็กดดูประวัติ commit แล้วย้อนกลับได้เสมอ นั่นคือเหตุผลที่เราใช้ Git

## แผงข้อมูลการเชื่อมต่อ

ส่วนล่างของหน้าอ่านค่าจาก Performance API ของ browser ค่าทุกตัวมาจากการโหลดหน้านั้นจริง
ไม่ได้เขียนค้างไว้ นำไปเปรียบเทียบกับ DevTools (F12) → Network ได้โดยตรง ใช้ทำ Mission 2

รายละเอียดว่าแต่ละค่าหมายถึงอะไร อ่านที่ใบความรู้ที่ 3.1 หัวข้อ 2–5

## ภารกิจเสริม — เวอร์ชันแยกไฟล์ (`bonus/`)

โฟลเดอร์ [`bonus/`](bonus/) เป็นเว็บเดียวกันแต่แยกออกเป็น 3 ไฟล์

```
index.html          หน้าเว็บ
style.css           สไตล์ทั้งหมด
data/profile.json   ข้อมูลของผู้ใช้
```

เวอร์ชันนี้แยกข้อมูลออกจากการแสดงผล ไฟล์ HTML ไม่ได้เก็บชื่อไว้เลย แต่ใช้ `fetch()`
ไปขอจาก `profile.json` อีกทีหนึ่ง เปิด DevTools → Network แล้วรีเฟรช
จะเห็นว่าทั้งสองไฟล์เป็นคนละ request กัน

นี่คือแนวคิดเดียวกับที่ระบบขนาดใหญ่ใช้ และเป็นภารกิจเสริมที่เหมาะสำหรับผู้ที่ทำ Mission 1 เสร็จก่อนเวลา

> ⚠️ เวอร์ชันนี้ต้องเปิดผ่าน URL เท่านั้น หากดับเบิลคลิกเปิดจากเครื่อง (`file://`)
> browser จะบล็อกการอ่านไฟล์อื่นตามกฎ same-origin ซึ่งเป็นหลักความปลอดภัยพื้นฐานของเว็บ

## แก้ไขทั้งหมดเองได้หรือไม่

ได้ และควรทำ ไฟล์นี้เป็นเพียงจุดเริ่มต้นให้เว็บใช้งานได้เร็ว เมื่อ deploy ได้แล้ว
ให้ทดลองแก้ไขต่อได้เต็มที่ Git เก็บทุกเวอร์ชันไว้ให้ย้อนกลับได้เสมอ
