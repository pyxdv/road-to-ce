# GitHub Profile README

โฟลเดอร์นี้มีเทมเพลตสำหรับหน้า **profile** ของคุณบน GitHub พร้อมตัวอย่างโปรไฟล์จริง
ของนักพัฒนาทั่วโลกไว้ให้ดูเป็นแนวทาง

## หน้า profile คืออะไร และทำไมต้องสนใจ

หน้า `https://github.com/<username>` คือหน้าที่คนอื่นเห็นเมื่อค้นชื่อคุณเจอบน GitHub
ในสายงานพัฒนาซอฟต์แวร์ ผู้ว่าจ้างและรุ่นพี่จำนวนมากเปิดดูหน้านี้ควบคู่ไปกับ resume
เพราะเป็นที่เดียวที่เห็น **งานจริง** ไม่ใช่แค่คำบรรยายว่าทำอะไรเป็น

โดยปกติหน้านี้จะมีแค่รายการ repository เรียงกัน แต่ GitHub มีกลไกพิเศษอยู่อย่างหนึ่ง

> ถ้าคุณสร้าง repository ที่ **ชื่อเดียวกับ username ของคุณเป๊ะ ๆ** แล้วใส่ไฟล์ `README.md`
> ไว้ข้างใน เนื้อหาในไฟล์นั้นจะขึ้นแสดงบนสุดของหน้า profile ทันที

ตัวอย่าง ถ้า username คือ `somchai-dev` ให้สร้าง repository ชื่อ `somchai-dev`
GitHub จะขึ้นข้อความว่า *"You found a secret! somchai-dev/somchai-dev is a special repository..."*
นั่นแปลว่าคุณตั้งชื่อถูกแล้ว

## วิธีทำ

1. ที่ GitHub กดปุ่ม **+** มุมขวาบน → **New repository**
2. ตั้งชื่อ repository เป็น **username ของคุณ** ทุกตัวอักษร
3. เลือก **Public** และติ๊ก **Add a README file**
4. กด **Create repository**
5. เปิดไฟล์ `README.md` แล้วกดรูปดินสอเพื่อแก้ไข
6. เลือกเทมเพลตหนึ่งแบบจากตารางด้านล่าง เปิดไฟล์นั้น กด **Copy raw file** แล้ววางแทนของเดิม
7. แก้ข้อความในวงเล็บเหลี่ยม `[ ]` ให้เป็นของตัวเอง แล้วลบวงเล็บออก
8. กด **Commit changes**
9. เปิด `https://github.com/<username>` ดูผลลัพธ์

## เขียนอะไรลงไปดี ในเมื่อยังไม่มีผลงาน

ปี 1 เทอมแรกยังไม่มีผลงานเป็นเรื่องปกติ และไม่มีใครคาดหวังว่าจะมี
สิ่งที่เขียนได้ตั้งแต่วันนี้และมีค่าจริงคือ

| เขียนแบบนี้ | อย่าเขียนแบบนี้ |
|---|---|
| "กำลังเรียน HTML และ CSS อยู่ตอนนี้" | "เชี่ยวชาญ Full-stack Development" |
| "อยากทำระบบรดน้ำต้นไม้ที่ดูพยากรณ์อากาศก่อนรด" | "รักการเขียนโปรแกรมและเทคโนโลยี" |
| "ยังอยู่ช่วงเริ่มต้น กำลังสะสมผลงานทีละชิ้น" | ปล่อยช่องผลงานว่างเปล่าโดยไม่อธิบาย |
| ใส่โลโก้ภาษาที่ **ใช้เป็นจริง** | ใส่โลโก้ 20 ภาษาที่ยังไม่เคยเขียน |

การเขียนตามจริงว่ากำลังเริ่มต้น ดูน่าเชื่อถือกว่าการเขียนเกินตัวเสมอ
คนที่อ่าน profile ของนักศึกษาปี 1 เขารู้อยู่แล้วว่าคุณอยู่ปี 1

## เรื่อง badge และการ์ดสถิติ

โปรไฟล์ที่เห็นบ่อยจะมีแถบโลโก้เครื่องมือและการ์ดสรุปสถิติ ใช้ได้และดูดีจริง
แต่ต้องรู้ว่ามันคืออะไรก่อน

- **badge ทุกอันคือรูปที่ดึงมาจากเว็บอื่น** (เช่น `img.shields.io`) ไม่ใช่ข้อมูลที่ GitHub รับรอง
  ใครก็ตั้งข้อความในนั้นว่าอะไรก็ได้ คนในสายงานจึงไม่ได้ดู badge แต่ดูผลงานที่ลิงก์ไว้
- **การ์ดสถิติเป็นบริการของบุคคลที่สาม** ถ้าบริการนั้นล่ม โปรไฟล์เราจะขึ้นรูปแตกทั้งหน้า
  ข้อมูลสำคัญจึงต้องมีเป็นข้อความจริงอยู่ด้วยเสมอ ไม่ใช่อยู่ในรูปอย่างเดียว
- **การ์ดภาษาที่ใช้ นับจำนวนไบต์ของโค้ด ไม่ได้วัดความสามารถ** ไฟล์ HTML ไฟล์เดียว
  ก็ทำให้ HTML ขึ้นเป็นอันดับหนึ่งได้
- ของประดับควรใช้เวลาไม่เกิน 10% ของเวลาทั้งหมด ที่เหลือใช้กับการเขียนว่าเราทำอะไรอยู่

รายละเอียดและลิงก์ที่ใช้ได้จริง อยู่ใน [`styles/visual.md`](styles/visual.md)

## ข้อควรรู้

- **กราฟสีเขียว (contribution graph) ไม่ใช่ตัวชี้วัดความสามารถ** อย่าสร้าง commit ปลอมเพื่อให้กราฟเขียว
  คนในวงการดูออก และมองเป็นสัญญาณลบมากกว่าบวก
- **สิ่งที่มีค่าจริงคือ README ที่อธิบายงานของตัวเองได้ชัดเจน** ความสามารถในการอธิบายสิ่งที่ทำ
  เป็นทักษะที่ประเมินได้จริงจากหน้า profile และเป็นทักษะที่ใช้ตลอดชีวิตการทำงาน
- **หน้านี้เป็นพื้นที่สาธารณะ** ห้ามใส่เบอร์โทรศัพท์ อีเมลส่วนตัว ที่อยู่ที่พัก เลขประจำตัวประชาชน
  หรือภาพบัตรประจำตัว ใช้ลิงก์สาธารณะเท่านั้น (ใบความรู้ที่ 3.1 หัวข้อ 11)
- **อย่าคัดลอกข้อความแนะนำตัวของคนอื่นมาทั้งดุ้น** ลอกได้เฉพาะโครงสร้างและวิธีจัดข้อมูล
- profile ของนักศึกษาปี 1 ยังไม่ทำให้ได้งาน แต่ profile ที่เริ่มสะสมตั้งแต่ปี 1
  และมีร่องรอยการเรียนรู้ต่อเนื่อง 4 ปี ทำให้ได้
