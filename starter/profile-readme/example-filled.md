## ทำไมตัวอย่างนี้ถึงใช้ได้ ทั้งที่ยังไม่มีผลงาน

| สิ่งที่ทำ | ทำไมถึงได้ผล |
|---|---|
| เขียนว่าอยากทำ "เครื่องวัดฝุ่นในห้องเรียน" | เจาะจงจนคนอ่านนึกภาพออก ต่างจาก "รักการเขียนโปรแกรม" ที่ไม่บอกอะไรเลย |
| บันทึกการเรียนรู้มีวันที่ | เห็นว่ามีความต่อเนื่อง ซึ่งเป็นสิ่งที่คนอ่านโปรไฟล์นักศึกษาปี 1 มองหาจริง ๆ |
| เขียนสิ่งที่เรียนไว้แค่ 3 ข้อ | ทั้งสามข้อเชื่อได้ ถ้าเขียน 15 ข้อจะไม่มีข้อไหนเชื่อได้เลย |
| บอกตรง ๆ ว่ายังอยู่ช่วงเริ่มต้น | ตรงกับความจริงที่คนอ่านรู้อยู่แล้ว จึงได้ความน่าเชื่อถือกลับมาแทน |
| ตอบได้ว่าถามเรื่องอะไรได้ แม้จะมีเรื่องเดียว | หนึ่งเรื่องที่อธิบายให้เพื่อนฟังได้จริง มีค่ากว่ารายการทักษะยาว ๆ ที่อธิบายไม่ได้สักอัน |
