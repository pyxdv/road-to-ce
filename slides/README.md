# slides — สไลด์เปิดคาบ

มีสองเวอร์ชันที่เนื้อหาเหมือนกัน เลือกใช้อันไหนก็ได้

| ไฟล์ | ใช้เมื่อใด |
|---|---|
| [`slides-3.1-opening.html`](slides-3.1-opening.html) | เปิดด้วย browser ได้ทันที ไม่ต้องมี PowerPoint · เลื่อนแผ่นด้วยแป้นพิมพ์ |
| [`slides-3.1-opening.pptx`](slides-3.1-opening.pptx) | ใช้กับ PowerPoint ตามปกติ · แก้เนื้อหาระหว่างสอนได้ |

ทั้งสองไฟล์มี **6 แผ่น** เนื้อหาตรงกันทุกแผ่น

## เนื้อหาในสไลด์

แผ่นที่ 1–5 คือสไลด์เปิดคาบ **ใช้เวลารวมประมาณ 2 นาที**
ออกแบบให้ใช้คู่กับการสาธิตสด ไม่ได้ออกแบบให้อ่านแทนการพูด ทุกแผ่นมีบันทึกผู้บรรยาย
(speaker notes) กำกับเวลาและสิ่งที่ควรพูดไว้แล้ว

| แผ่น | เนื้อหา | เวลา |
|---|---|---|
| 1 | 90 นาทีจากนี้ เว็บของคุณจะเปิดได้จากทุกที่ในโลก | ~20 วิ |
| 2 | **สาธิตสด** — ให้นักศึกษาเปิดเว็บของผู้สอนบนมือถือ | ~30 วิ |
| 3 | กด Enter แล้วเกิดอะไรขึ้นบ้าง (DNS → Connect → HTTP → Render) | ~30 วิ |
| 4 | 90 นาที 5 ภารกิจ | ~25 วิ |
| 5 | กฎข้อเดียวก่อนเริ่ม: ทุกอย่างที่ขึ้นวันนี้เป็นสาธารณะ | ~15 วิ |
| 6 | **ไม่ใช่แผ่นเปิดคาบ** — สไตล์ profile 4 แบบ ใช้ตอนเข้า Mission 4 (นาทีที่ ~75) | ~40 วิ |

แผ่นที่ 6 ตั้งใจให้ข้ามตอนเปิดคาบ แล้วย้อนกลับมาเปิดตอนเข้า Mission 4
เนื้อหาตรงกับ [`starter/profile-readme/`](../starter/profile-readme/) ทั้งหมด

## วิธีใช้ไฟล์ `.html`

ดับเบิลคลิกเปิดได้เลย ไม่ต้องต่อเน็ต ไม่ต้องติดตั้งอะไร แล้วกด **F11** เพื่อเต็มจอ

| ปุ่ม | ทำอะไร |
|---|---|
| `←` `→` `Space` | เปลี่ยนแผ่น (คลิกซ้าย/ขวาของจอก็ได้) |
| `1`–`6` | กระโดดไปแผ่นที่ระบุ |
| `N` | เปิด/ปิดบันทึกผู้บรรยาย |
| `Ctrl`+`P` | บันทึกเป็น PDF ได้แผ่นละหน้า |

เลขแผ่นปัจจุบันติดอยู่ที่ URL (`...html#3`) ถ้าเผลอปิดหน้าต่างจะกลับมาที่แผ่นเดิมได้

## ⚠️ ต้องแก้ก่อนใช้สอน

**แผ่นที่ 2 มี URL ตัวอย่างว่า `https://your-name.github.io` ให้เปลี่ยนเป็นเว็บของผู้สอนเอง
ทั้งในไฟล์ `.html` และ `.pptx`** (ในไฟล์ `.html` มีคอมเมนต์ `<!-- แก้ URL -->` กำกับจุดที่ต้องแก้ไว้แล้ว)

ทั้งแผ่นนี้อยู่ได้ด้วย URL จริงเท่านั้น เพราะจังหวะที่ทั้งห้องพิมพ์ตามแล้วเว็บขึ้นบนมือถือตัวเอง
คือจุดที่ทำให้นักศึกษาเชื่อว่าเรื่องนี้เป็นของจริง

## ⚠️ ฟอนต์ — ต้องติดตั้งก่อนใช้สอน

สไลด์ทั้งสองเวอร์ชันใช้ **IBM Plex Sans Thai** คู่กับ **IBM Plex Mono**
เส้นหนากว่า TH Sarabun New จึงอ่านชัดเมื่อฉายขึ้นจอใหญ่ และดูสะอาดกว่า Tahoma

ทั้งสองตัวเป็นฟอนต์ฟรี ดาวน์โหลดที่ [fonts.google.com](https://fonts.google.com)
ค้นคำว่า *IBM Plex Sans Thai* และ *IBM Plex Mono* แล้วติดตั้งลงเครื่องที่จะใช้สอน

**ถ้าเครื่องไหนไม่ได้ติดตั้ง สไลด์ยังเปิดได้ตามปกติ** เพียงแต่จะถูกแทนด้วยฟอนต์อื่น
ไฟล์ `.html` ไล่ลำดับสำรองไว้ให้แล้ว (Tahoma → Leelawadee UI → ฟอนต์ระบบ)
ส่วน `.pptx` PowerPoint จะเลือกแทนให้เอง ซึ่งควบคุมหน้าตาไม่ได้

อยากกลับไปใช้ฟอนต์ที่มีติดมากับ Windows อยู่แล้ว ให้แก้ค่า `TH` และ `MONO` ด้านบนไฟล์
[`tools/build_slides.js`](tools/build_slides.js) เป็น `'Tahoma'` กับ `'Courier New'` แล้วสร้างใหม่
และแก้ตัวแปร `--th` กับ `--mono` ในไฟล์ `.html` ให้ตรงกัน

ไม่ควรใช้ TH Sarabun New กับสไลด์ เพราะเส้นบางเกินไปเมื่อฉายขึ้นจอใหญ่
(เอกสาร `.docx` ของรายวิชายังใช้ TH Sarabun New ตามเดิม ไม่เกี่ยวกับสไลด์)

## สร้างไฟล์ใหม่

```bash
cd slides/tools
npm install pptxgenjs      # ครั้งแรกครั้งเดียว
node build_slides.js
```

ไฟล์ผลลัพธ์จะอยู่ในโฟลเดอร์เดียวกับสคริปต์ ให้ย้ายมาไว้ที่ `slides/`

> แก้ `.pptx` ใน PowerPoint ได้ตามปกติ ถ้าแก้แล้วอย่ารันสคริปต์ซ้ำ เพราะจะเขียนทับ

ส่วนไฟล์ `.html` ไม่มีสคริปต์สร้าง แก้เนื้อหาในไฟล์ได้โดยตรง แต่ละแผ่นคือบล็อก `<section class="slide">`
หนึ่งบล็อก และบันทึกผู้บรรยายอยู่ในแอตทริบิวต์ `data-notes` ของบล็อกนั้น

> แก้เนื้อหาแผ่นไหนก็ตาม ให้แก้ทั้ง `.html` และ `build_slides.js` ไม่งั้นสองเวอร์ชันจะไม่ตรงกัน
